# Drift (Plumbr desktop) features

Every feature the website (theplumbr.com) promises, what it means in the app, and how it runs. Source of truth for the copy is `lib/content.ts` in the `theplumbr` repo. Status is for the desktop app in this repo.

Legend for "Runs": **local** = entirely on the user's machine, no Plumbr server. **local + third party** = local app talking to a service the user already uses with their own credentials. **needs relay** = needs a small hosted component that Plumbr operates.

## Headline

**Stop copy-pasting secrets into every platform.** Local-first desktop app for macOS, Windows and Linux. Values redacted by default. Every sync human-approved.

## Comparison claims (from /alternatives) the app must keep true

- Runs as a desktop app, nothing to host.
- Discovers existing `.env` files in place. Files stay in project folders.
- Redacted drift receipts between environments.
- Every sync reviewed and human-approved.
- Sync to GitHub, Vercel, Railway, Render and friends. AWS Secrets Manager and Vault as sources.
- Encrypted, self-destructing share links.
- MCP context for AI coding agents, no values.
- Cross-platform: macOS, Windows, Linux.

## FAQ promises the app must keep true

- Never move, copy or rewrite `.env` files unless the user approves an exact plan.
- "Redacted by default": receipts, plans and MCP show key names and classes only. Values are fingerprints on the machine and never displayed by default.
- MCP cannot execute a sync and never receives raw values.
- No scheduled or automatic production sync. No unattended write path.
- Share links expire on a timer or after N opens, can be revoked, leave nothing in chat. Sealed on device before leaving. Recipient needs no account.
